        How to get a free API key
        1. Create a free account at openweathermap.org.
        2. Open API keys in your account and copy the default key.
        3. Paste it above and press Save weather settings.
        4. New keys can take up to a couple of hours to start working. Demo data shows until then.

        Prefer no sign-up? Pick Open-Meteo as the provider. It is free and needs no key.

        Your key is stored only in this browser, in extension storage.
